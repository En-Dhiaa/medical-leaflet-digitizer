# المحوّل الذكي للنشرات الدوائية | Smart Medical Leaflet Digitizer

نظام ويب تفاعلي متقدم لتحويل وتفريغ صور النشرات الدوائية (النشرات الداخلية للأدوية والمستحضرات الصيدلانية) إلى وثائق رقمية عالية الدقة مطابقة للمواصفات الرسمية، مع دعم التعديل المباشر، وتغيير الخطوط، والرفع الذكي المتعدد، والتصدير الفوري بصيغة PDF.

---

## 🌟 المميزات الرئيسية (Key Features)

1. **الرفع الذكي للصور المتعددة (Smart Multi-Image Upload):**
   - إمكانية سحب وإفلات أو رفع صور متعددة لنفس الدواء (الوجه العربي + الوجه الإنجليزي).
   - بطاقات معاينة تفاعلية لكل صورة مع زر للتدقيق والمقارنة.

2. **الاستخراج الآلي للنصوص (In-Browser OCR):**
   - مدمج بمكتبة الذكاء الاصطناعي `Tesseract.js` لقراءة النصوص العربية والإنجليزية مباشرة من المتصفح دون الحاجة لسيرفر خارجي.
   - توزيع تلقائي ذكي للنصوص المستخرجة داخل أقسام النشرة.

3. **وضع المقارنة الحية المباشرة (Side-by-Side Comparison):**
   - تقسيم الشاشة لعرض صورة النشرة الأصلية المصورة بجانب المستند الرقمي لسهولة المراجعة والتدقيق والتعديل الفوري للجرعات والتركيزات.

4. **تصدير PDF فوري بدون نافذة طباعة (Direct PDF Export):**
   - حفظ مباشر وبنقرة واحدة في مجلد التنزيلات (`Downloads`) بدقة فائقة (`300 DPI / 2x Retina`).
   - ضبط دقيق لأبعاد الورق (A4) بحيث تظهر النشرة كاملة بدون صفحات بيضاء فارغة وبدون أخطاء تقسيم.
   - دعم تصدير صفحتين (صفحة 1 عربي، صفحة 2 إنجليزي) أو صفحة واحدة حسب العرض المختار.

5. **تخصيص الخطوط والأحجام (Font Customizer):**
   - خطوط عربية متعددة: **تجوال (Tajawal)**، **كايرو (Cairo)**، **المراعي (Almarai)**، **أميري (Amiri)**، **تهوما (Tahoma)**، **أريال (Arial)**، **نوتو سانس**.
   - خطوط إنجليزية: **Roboto**, **Arial**, **Times New Roman**, **Segoe UI**, **Georgia**.
   - أزرار تصغير وتكبير حجم الخط (`A-` و `A+`) لضبط ملء الصفحة بدقة متناهية.

6. **تعديل مباشر وحفظ سحابي محلي (Live Inline Editing & Auto-Save):**
   - النقر المباشر على أي عنوان، فقرة، جرعة، أو جدول لتعديلها كما في برامج معالجة الكلمات.
   - حفظ التعديلات في الذاكرة المحلية للمتصفح (`LocalStorage`) للبقاء حتى بعد إغلاق المتصفح أو إعادة تشغيل الجهاز.

7. **تنسيق دوائي معتمد (Pharmaceutical Leaflet Standards):**
   - تقسيم العمودين الكلاسيكي للنشرات الدوائية المطوية.
   - خطوط النقاط المتقطعة لجدول التركيب الدوائي (`Dotted Leaders`).
   - الإطار الرسمي لصندوق **تعليمات للمريض (مجلس وزراء الصحة العرب وإتحاد الصيادلة العرب)**.
   - شعار رسمي فيكتور نقي (SVG) عالي الدقة للجهة المصنعة.

## 🚀 طريقة الاستخدام السريعة (Quick Start)

1. افتح الملف `index.html` في أي متصفح حديث (Google Chrome, Microsoft Edge, Firefox, Safari).
2. انقر على **`📸 رفع صور جديدة`** لرفع صور نشراتك الخاصة واستخراج نصوصها.
3. استخدم زر **`👁️ مقارنة مع الأصل`** للتدقيق كلمة بكلمة ضد الصورة الأصلية.
4. استخدم زر **`✏️ تعديل النص`** لإجراء أي تعديلات، ثم **`💾 حفظ`**.
5. انقر على **`📥 حفظ PDF فوري`** لتحميل ملف الـ PDF الجاهز للطباعة فوراً في مجلدك!
